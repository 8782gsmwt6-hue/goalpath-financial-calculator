# GoalPath Financial Calculator

A private, mobile-friendly financial goal planner that runs entirely in the browser and can be hosted free on GitHub Pages.

## Included features

- Time-to-goal calculator
- Required monthly investment calculator
- Second-home cash-goal planner
- Inflation-adjusted goals
- Home-price appreciation
- Investment fee adjustment
- Annual contribution increases
- Three-scenario comparison
- Assumption checker
- Projection chart and annual table
- Saved goals using browser local storage
- Export/import backup
- Research links to BLS, Investor.gov, FHFA, Freddie Mac, CFPB, and NYU historical return data
- Dark mode
- No bank connection, account, API, or server required

## GitHub Pages setup

1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, and `app.js` to the repository root.
3. Open repository **Settings**.
4. Select **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**.
7. Click **Save**.
8. After GitHub publishes the site, open the displayed URL.

## Privacy

Goals are stored in browser local storage on the device/browser being used. They are not placed in GitHub. Export backups periodically because clearing browser website data may erase saved goals.

## Important

This application provides deterministic planning illustrations, not predictions, investment advice, tax advice, or guarantees. Actual investment returns, inflation, taxes, fees, and goal costs can differ.
